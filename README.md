# 打工人决策台 🧭

> 1024 程序员节参赛作品：跳槽季的六个硬核工具。纯前端、零依赖、数据全部本地处理。

**在线体验**：<https://workbuddy.link/p/bEQGbhq3YtrL5VODQXoL0q>

## 功能

| 模块 | 说明 |
|---|---|
| ⚖️ Offer 对比器 | 综合年包（现金 + 公积金 + 期权折算）、真实时薪、年通勤时间，自动排序与决策提示；填写内容自动保存在本机 |
| 🎯 JD 匹配分析 | 简历保存一次长期使用；粘贴 JD 即出关键词覆盖率与缺失项排序，缺失项附「速学卡片」（一句话定义 / 核心要点 / 高频问答 / 学习路径，内置 37+ 张，未覆盖项走通用学习框架） |
| 💰 离职补偿计算器 | N / N+1 / 2N，工龄精确到月，社平 3 倍封顶与 12 年上限，附法条依据与谈判提示 |
| 🧾 年终奖个税优化 | 单独计税 vs 并入综合所得自动对比给结论，内置 6 个「多发一元少拿千元」无效区间检测 |
| 📝 面试复盘库 | 按类别自动归档的跨公司「面试错题本」，一键导出 Markdown 综合文档（类别汇总 + 公司时间线 + 高频薄弱点） |
| 📋 离职小抄 | 被裁沟通 / 竞业 / 社保衔接 / 年假折算等要点，附各地政策差异速览 |

## 为什么是「真实工具」而不是展示页

- **确定性计算，可测试**：税费与补偿金都是规则计算，没有黑盒。页面底部内置「🧪 计算器自检」，一键运行内置测试用例（工龄折算、N 月数、年终奖税额、无效区间、Offer 总包公式），当场验证计算口径
- **隐私优先**：简历、Offer、面试记录全部保存在浏览器 localStorage，无后端、不上传、无追踪
- **反馈闭环**：问题与功能建议请提 [Issue](https://github.com/HadesWing/WorkBuddy/issues)，会按类别归档处理
