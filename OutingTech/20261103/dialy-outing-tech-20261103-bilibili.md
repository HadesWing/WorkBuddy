**核心卖点：** Auto Ontology 是英伟达开源的一个库（Apache 2.0），解决的问题是"智能体分析的可信度闸门"——一个营收数字答得再快，如果数字是错的就毫无价值。它从企业元数据自动生成本体（ontology），跨系统对齐定义，并通过 MCP、CLI、API 把这层上下文暴露给任意 Agent 框架：Discover 发现数据在哪、Ground 给出指标与实体的可信业务含义、Validate 校验生成查询并返回溯源、Learn 把人工修正回写进本体让它越用越准。户外相关性体现在一个很实际的场景：野外数据采集（传感器、巡检、救援日志）天然异构、口径不统一，一套能让 AI 可靠引用来源并附带 lineage 的上下文层，正是"AI 参与野外决策"的前置条件。

**核心卖点：** AgentKit 是 Scalekit 推出的智能体集成平台，核心是一个 MCP 网关：600+ 应用连接器、30,000+ 工具统一在单个 MCP 端点之后，对外提供正确的凭据、权限检查与可读响应；支持 per-user token、虚拟 MCP 服务器、按 Agent 角色限定工具范围、事件触发器、每次调用可归因到具体用户，另配 BYOK、VPC 与合规选项。这套东西解决的是一个在外场非常具体的难题：**野外装备与户外服务系统正被大量 AI 智能体接入，如何在开放环境里既给足能力、又不把权限开成敞门**。户外数据平台、装备厂商的设备云、救援调度系统——凡是要让 Agent 真的"动手"而不只是"说说"，中间这层鉴权与审计网关都是必需品。
